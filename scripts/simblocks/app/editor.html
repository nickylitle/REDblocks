Studies

Type single values straight into a node. To vary one, plug a Range of values or Monte Carlo node into that input. Study runs every sweep value against every Monte Carlo sample on the cores picked in the top bar, and asks first when that is more than 100 runs or about a minute of work.

How it maps

Value nodes become params (or derived when they start with =). Builder nodes call catalog blocks in derived. An element's body sockets and their factors write its measure. Load nodes are force elements. Range and Monte Carlo nodes fill study and uncertain. Output and Failure nodes fill outputs and failure. The units dropdown (top bar) is saved as units. The file stays plain YAML that simblocks run reads.
Press Run to see outputs and time histories.
Press Verify to run the full battery: dt convergence, energy ledger, knockouts, limits, Monte Carlo and your failure modes.

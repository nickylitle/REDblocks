Findings

  • Worst overall (sample 110): bending impulse 7.85 N s at the tip, signed components X -6.63, Y -7.62, Z +1.87 N s; peak 28698 N, almost all in-plane (Y 28448 N). The current load (two half-sines, Z only) carries 2.30 N s at 6110 N.
  • Every top-8 candidate in both rankings converged with time step (harness criterion, < 1%).
  • Worst out-of-plane (sample 11): Z impulse +2.81 N s, Z peak 5884 N, 1 pulse(s).
  • Why in-plane governs: the arm is 30 mm wide and 6.35 mm thick, so it carries about (W/t)^2 = 22x more stiffness and 4.7x more yield load in-plane. A horizontal blade is hit mostly in its own plane.
  • Tables (bending only, X = 0): 34 and 32 points, impulse kept exactly. Dense files at 2.5 us include radial X: its impulse is reliable (-6.63 N s worst overall) but its peak is set by the contact stiffness (no tooth crushing).

Assumptions

  • Ranking uses the bending components (in-plane Y + out-of-plane Z). Radial X is exported too: in jammed engagements the tooth pushes inward along the arm for several ms (up to about 13 N s), which loads the hub and mount axially but does not bend the blade.
  • Flapjack's blade strength scaled x0.99 so the most it can pass out-of-plane (full plastic collapse with hardening) is 6110 N at the tip (your bending load); in-plane strength scales with it. Blade 30 x 6.35 mm, 190 mm tip to tip, arms bend from a 12.5 mm clamp radius (82.5 mm lever). AR500 curve shape, stiffness unchanged.
  • Engagements reuse the study's inputs (phases, closing 2-4 m/s, offset, heading, restitution, friction, rpm); the vertical is the same placeholder bar, both blades bend.
  • Load = the arm's first-mode spring force on the rigid blade. Higher bending modes, torsion and tooth crushing (which would cap the in-plane peak lower) are not modelled.
  • Arm frame: X radial out, Y along the direction of rotation, Z up.
